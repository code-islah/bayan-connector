🌐 Bayan Connector

A modern full-stack social media web application built with React, Node.js, Express, MongoDB, and Socket.IO.


---

🚀 Live Demo

🔗 https://bayan-connector.vercel.app/


---

📌 Features

👤 Authentication

User registration & login (JWT based)

Protected routes


📝 Posts

Create posts with images

Delete posts (with Cloudinary cleanup)

Dynamic feed rendering


❤️ Reactions

Like system with emoji reactions


💬 Comments

Add comments to posts

Display user-specific comments


💬 Real-time Chat

One-to-one messaging

Socket.IO integration


🧾 Profile Management

Update name

Upload profile picture (Cloudinary)

⚙️ Installation

1. Clone the repository
git clone https://github.com/code-islah/bayan-connector.git
cd bayan-connector

2. Install dependencies

Backend

cd server
npm install

Frontend

cd client
npm install


---

🔐 Environment Variables

Create a .env file in the server folder:

MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret


---

▶️ Run Locally

Backend

npm run start

Frontend

npm run dev
